# Srinath V — Business Intelligence & Analytics Portfolio

A responsive portfolio website designed for recruiter scanning and built from the resume and three analytics project repositories.

## Preview locally
Open `index.html` in a browser. The site uses embedded CSS and does not require a build step or external JavaScript libraries.

## Publish with GitHub Pages (free)
1. Create a new **public** repository named `srinath50090.github.io` under your GitHub account.
2. Upload `index.html`, the `assets` folder, and this `README.md` to the repository root.
3. Open the repository and select **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for deployment, then use the URL shown under Settings → Pages. The expected user-site URL is `https://srinath50090.github.io/`.
7. After publishing, test the page on mobile and desktop and verify all project, contact, and resume links.

Official guide: https://docs.github.com/en/pages/quickstart
